My Online Shop

This is a completely separate website — could be AEM, Shopify, WordPress, a React app, or a plain HTML page. The StreamX chat widget is embedded below using just two lines of code.

The widget is a Web Component backed by Shadow DOM, so its styles are fully isolated — no CSS collisions with this page whatsoever.

How to embed

Add these two lines to any HTML page:

<script type="module"
  src="https://chat.streamx.io/streamx-chat.js"></script>

<streamx-chat
  api-url="https://rag.streamx.io"
  title="Product Assistant"
  placeholder="Ask about any product…"
  auto-open="2000">
</streamx-chat>
Attributes:
api-url — URL of the RAG service (required)
title — header title (default: "Product Assistant")
placeholder — input placeholder text
auto-open — auto-open delay in ms (omit to disable)

Scroll down or look at the bottom-right corner for the chat bubble.
